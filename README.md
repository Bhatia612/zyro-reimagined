# Zyro - Reimagined

An unofficial landing-page concept for **Zyro**, the zero-sugar beverage brand
by Karan Aujla. A personal frontend study in scroll-driven motion design with
GSAP. Not affiliated with Zyro.

> Work in progress. Not yet deployed.

## Stack

React (Vite), GSAP + ScrollTrigger, Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Brand video and logo assets aren't included in the repo. Supply your own in
`src/assets/branding/`.
